# Web Scraping & Text Extraction (NLP)

A Natural Language Processing (NLP) project contained in `NPL_TP_Ext_de_texto.ipynb`, focused on collecting and extracting text data via web scraping.

## Project Structure

- `NPL_TP_Ext_de_texto.ipynb` — Jupyter notebook containing the web scraping and text extraction workflow.

## Usage

1. Open `NPL_TP_Ext_de_texto.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
2. Install any required scraping and NLP dependencies referenced inside the notebook.
3. Run the cells sequentially to extract and process text data.
